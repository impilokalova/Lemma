# Lemma asset upload inbox

Upload new images, videos, and other creative assets into this `assets/` folder.

This folder is a staging inbox, not the final production asset location. When integrating an asset into a landing page or case study, move/copy it to the relevant site directory, update the code references, and verify the deployed result.

Please use descriptive filenames (for example, `sole-system-side-view.webp`) and avoid uploading secrets, licensed material without permission, or unnecessarily large source files.
