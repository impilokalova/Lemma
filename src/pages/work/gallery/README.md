# Signature artwork collection

The 12 source PNG files are already in `src/pages/packages/` (uploaded through GitHub). The gallery registry `artworks.ts` imports them, and Vite bundles their URLs. Add future images to a dedicated `src/pages/work/gallery/assets/` folder and update the imports and registry. The live collection is `/work/templates`; each detail page is `/work/templates/:slug`. All works are fictional concept samples, not commissioned clients.
