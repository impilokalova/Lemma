# Studio visual refresh

Adapted from `usernamestack/Lemma-Template-Library`:

- `Building Blocks/Desktop/Buttons and Controls/Buttons/Liquid Glass Lens`: translucent edges and the trailing circular arrow in `StudioLink`.
- `Building Blocks/Desktop/Buttons and Controls/Buttons/Luminous Glow`: inset glow surfaces on service cards and action icons.
- `Building Blocks/Desktop/Motion and Interaction/Carousels/Animated Image Slider`: image/copy transitions, adapted as a React showcase. The source includes MDJAmin attribution; it is retained here and in the component comment.

The adaptations use Lemma's violet palette, responsive layout, visible labels, native buttons, and reduced-motion support. The showcase uses manual navigation with screen-reader announcements. Projects remain explicitly marked as fictional concepts.

Existing quotation calculations, WhatsApp configuration, enquiry delivery, SEO settings, and concept page destinations remain in place.
